# CG-Reports
[Lab6- Creating two diomensional objects]

Discussion

In this laboratory experiment, two-dimensional (2D) objects were created using fundamental computer graphics techniques. The objective was to understand how geometric primitives such as points, lines, rectangles, circles, and polygons are represented mathematically and rendered on a display device.

The experiment demonstrated that every 2D object is constructed using coordinate systems. The Cartesian coordinate system plays a crucial role in positioning objects accurately on the screen. By specifying coordinate pairs (x, y), shapes can be precisely defined and manipulated. The process also highlighted the importance of transformation operations such as translation, scaling, and rotation, which allow objects to move, resize, and rotate within the viewing area.

During the implementation, it became clear that algorithms such as line drawing and circle drawing are essential for efficient rendering. These algorithms help in plotting pixels in a structured and optimized manner. The experiment also provided insight into how graphics libraries simplify complex mathematical computations and allow users to focus more on design and structure.

Furthermore, creating 2D objects helped in understanding the relationship between mathematical concepts and visual representation. It strengthened the understanding of coordinate geometry, transformation matrices, and rendering pipelines. Any errors encountered during object positioning emphasized the need for careful calculation and logical structuring of code.

Overall, the experiment provided practical exposure to fundamental graphics concepts and enhanced programming skills related to visual object creation.

Conclusion

From this experiment, it can be concluded that the creation of two-dimensional objects is the foundation of computer graphics. Understanding how basic geometric shapes are constructed and displayed is essential before progressing to advanced topics such as three-dimensional modeling, animation, and rendering.

The lab activity improved our understanding of coordinate systems, graphical primitives, and transformation techniques. It also demonstrated how mathematical principles are directly applied in computer graphics programming.
